<summary><strong>⬡ &nbsp;Campus Navigation Website &nbsp;<img src="https://img.shields.io/badge/Status-In_Progress-A855F7?style=flat-square" /></strong></summary>

<br/>

A web application designed to help students and visitors navigate a university campus with ease. The platform provides interactive routing, location search, and campus map features, backed by a Python/Flask API and a MongoDB database storing location and map data.

| Attribute | Detail |
|-----------|--------|
| **Stack** | React · CSS · JavaScript · Flask · Python · PyMongo · MongoDB |
| **Scale** | Campus-wide utility · Multi-user web application |
| **Performance** | React frontend for fast, dynamic UI · Flask REST API for data serving |
| **Security** | Backend API validation · MongoDB access control |
| **Impact** | Solving real navigation challenges for students at VIT Bhopal · Currently in active development |
| **Repository** | [![GitHub](https://img.shields.io/badge/View_Repo-6D28D9?style=flat-square&logo=github&logoColor=white)](https://github.com/SheersakSaha15) |

The frontend is built in React with a component-driven architecture, rendering an interactive campus map with location markers and search functionality. The Flask backend exposes REST API endpoints that query a MongoDB database containing structured campus location data managed via PyMongo. The project is currently under active development with planned features including turn-by-turn navigation and accessibility-aware routing.
